# How do I use this?

Follow the [instructions](https://github.com/grpc-ecosystem/grpc-gateway#usage) in the [README](https://github.com/grpc-ecosystem/grpc-gateway#readme).

## Serving an OpenAPI UI

To serve a Swagger UI alongside the gateway from the same server, see
[johanbrandhorst/grpc-gateway-boilerplate](https://github.com/johanbrandhorst/grpc-gateway-boilerplate),
which generates OpenAPI v2 with `buf` and serves the UI together with the gRPC-Gateway server.
